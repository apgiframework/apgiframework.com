Mechanistic Architecture

The framework decomposes conscious access into six quantifiable, interacting subsystems. Each module is designed for falsifiable prediction.

Active Inference Engine

Implements variational free energy minimization through hierarchical predictive coding across 4 distinct temporal scales (10ms to 500ms).

Precision Weighting

Dynamically allocates attentional resources by modulating the gain on prediction errors, balancing sensory input against prior beliefs.

Allostatic Regulation

Models physiological states (heart rate, cortisol, glucose) to maintain homeostatic balance via interoceptive predictive processing.

Ignition Dynamics

Simulates global workspace broadcasting with threshold-based ignition events, precisely matching the 300-500ms timeline of conscious access.

Self-Model System

Maintains minimal and narrative self-representations, continuously tracking coherence and monitoring autobiographical integrity.

Thermodynamic Constraints

Enforces biologically plausible metabolic budgets, tracking energy constraints and entropy costs of high-precision neural computation.

Empirical Validation

Built for Experimental Paradigms

A model is only as good as its predictions. The APGI System includes pre-configured experimental tasks to validate its outputs against established cognitive phenomena.

  • Attentional Blink & Masking

    Tests temporal attention limitations and subliminal threshold detection.

  • Binocular Rivalry

    Models competitive neural dynamics when conflicting stimuli are presented.

  • Iowa Gambling Task

    Assesses decision-making under uncertainty and somatic marker hypothesis validation.

import apgi

# Initialize the hierarchical predictive coding model
model = apgi.CognitiveArchitecture(
    layers=[256, 128, 64, 32],
    timestep_ms=1,
    allostasis_enabled=True
)

# Simulate a somatic marker triggering ignition
stimulus = apgi.Stimulus(type="threat", intensity=0.8)
state = model.step(stimulus)

if state.ignition_threshold_crossed:
    print(f"Conscious access achieved at {state.timestamp}ms")
    model.export_metrics(format="csv")
