# APGI Framework — apgiframework.com

Production web frontend for the APGI Framework (Allostatic Precision-Gated Ignition) — a pre-registered computational model of consciousness ignition, precision-gated attention, and allostatic regulation.

The site is currently a placeholder ("coming soon" homepage) while pre-launch remediation work completes. See [TASKS.md](TASKS.md) for the full outstanding-work list and [DEPLOY_PLAN.md](DEPLOY_PLAN.md) for the deployment plan.
